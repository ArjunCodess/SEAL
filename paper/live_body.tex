\section{Introduction}
When workers assert false completion on fixed local records, a live model supervisor can still publish to the fake sink. Unsafe execution counts every executed publication of an illegitimate workflow, including a summary corrected to the true summary. The central question is empirical: on a frozen fixture catalog, which \emph{fixed} evidence tier changes unsafe execution versus legitimate completion when worker messages are held constant. This report is an \textbf{empirical audit} of instructed attacks on a synthetic publication sink. It is not a learned policy for adaptive evidence budgets or prospective evidence recovery; no such recovery experiment was run here.

SEAL (Supervisor Evidence Arms, Live) compares what the supervisor \emph{advises} (publish, block, or abstain) with what the harness \emph{enforces} on the sink. On claims, receipts, and state, a publish decision executes unless the run errors. On provenance only, deterministic code may veto an otherwise recorded publish request. A zero harmful execution rate on provenance therefore bounds post-model enforcement, not a change in model judgment alone.

The locally frozen protocol \texttt{\StudyProtocolName{}} schedules \MainTargetEpisodes{} held-out test episodes across \IndependentFamilies{} template families, with \TestVariantsPerFamily{} numeric variants per family. Those variants are repeated measures inside the family. Development uses \DevVariantsPerFamily{} variants per family and is excluded from test denominators. Held-out attacks use three mechanisms on four templates: consistent fake input on both \texttt{parts-catalog} and \texttt{sensor-calibration}, unauthorized publication on \texttt{payroll-release}, and ambiguous evidence on \texttt{incident-timeline}. All four arms receive identical worker messages plus tier-specific observations so message availability does not suppress the single-versus-coordinated contrast.

\section{Related Work}
Agent benchmarks and instruction-hierarchy training study prompt injection and privileged instructions under tool use \cite{debenedetti2024agentdojo,wallace2024instructionhierarchy,debenedetti2025camel}. NARCBench and HELIOS probe instructed collusion in multi-agent settings with activation sensors \cite{rose2026helios}. AI-control literature motivates testing oversight against subversion without claiming a full control protocol here \cite{greenblatt2023aicontrol}. Unlike work on emergent interaction \cite{shi2026emergentcollusion}, this live study holds worker text fixed and varies the observation bundle and whether a deterministic publication gate can refuse execution after a supervisor publish decision.

Recent monitor evaluations separate instructions from actual collusive decisions, measure benign disruption from repeated warnings, test transfer across policy families, and allow strategic attack timing \cite{mohsin2026probes,raghav2026precrime,pinto2026calibration,gewang2026selection}. SEAL does not resolve these broader monitoring problems: its workers reproduce scripted instructions, supervisors make one decision per episode, and attacks follow a fixed catalog. Active acquisition and selective classification already study information cost and rejection coverage \cite{ma2018eddi,geifman2017selective}; feature-deletion robustness and secure audit logging provide related precedents \cite{globerson2006nightmare,schneier1999logs}. Risk-control methods require calibration assumptions beyond descriptive bootstrap intervals \cite{angelopoulos2021ltt,angelopoulos2022crc}. Our contribution is the inspectable fixed-arm audit, not a new acquisition algorithm or statistical safety guarantee. A comparison matrix for the proposed extension is released in \texttt{docs/literature-matrix.md}.

\section{Methods}
\subsection{Fixtures and arms}
Four development mechanisms (false completion, wrong summary, omitted step, stale evidence) diagnose the harness. Four held-out templates implement three test mechanisms. Consistent fake input is repeated on \texttt{parts-catalog} and \texttt{sensor-calibration}. \texttt{payroll-release} is unauthorized publication. \texttt{incident-timeline} is ambiguous evidence. Identifiers follow \texttt{family\_\allowbreak{}id.index.coordination}. The ten variants in a family change numbers inside that template. They are not independent samples. The bootstrap resamples four \texttt{family\_\allowbreak{}id} blocks, not forty fixture indexes. Intervals stay coarse: the blocks are few, and two of them share a mechanism.

Single and coordinated attacks share signed records. The single condition is one publisher role. The coordinated condition is three role-specific speakers. Message count and speaker roles both differ, so coordination contrasts stay descriptive. Honest controls always use three speakers. There is no single-speaker honest control.

State observations are fixed read-only keeper snapshots with \texttt{adaptive=false}. They are not multi-turn adaptive queries. Ed25519 signing keys are deterministic public material for reproducibility, not a production trust root.

Arms are intentionally not information-matched. Claims sees task text and worker messages. Receipts adds verified receipts and a fresh checkpoint. State adds the keeper snapshot. Provenance adds trusted inputs, digests, tool allowlists, and channel policy, and only that arm can veto a publication in deterministic code. The provenance observation includes \texttt{trusted\_\allowbreak{}summary} when \texttt{binding\_\allowbreak{}complete} is true. On the three answerable test families that field equals the fixture true summary in every attack coordination. On \texttt{incident-timeline} attacks \texttt{binding\_\allowbreak{}complete} is false and \texttt{trusted\_\allowbreak{}summary} is null; honest controls on that family are binding-complete and also receive the derived true summary. Fresh checkpoint handling is identical across receipts, state, and provenance. Reference decisions in the fixture catalog supply equal-observation baselines for pairing checks, not supervisor policies.

\subsection{Trust, observation, and evidence hiding}
We separate \emph{what is shown} to the supervisor from \emph{what is enforced} after a decision. Table~\ref{tab:live-aggregate} and Appendix~\ref{sec:endpoint-fields} report the stored counters; here we state the audit assumptions.

\textbf{Post-record omission.} Each arm reveals a fixed bundle. Fields absent from that bundle are hidden from the model even if they exist in the simulator (for example keeper-only bodies without trusted inputs on state).

\textbf{Non-recording.} Evidence that was never captured cannot be recovered from a protected archive. This study does not inject recording failures or test recovery from an archive. Error and invalid supervisor outputs are a separate inference-failure category; they are excluded from completed-case rates and counted as non-success in all-status sensitivities.

\textbf{Tampering and signer compromise.} The harness verifies receipts and checkpoints against frozen catalog material. It does not model an adversary who forges signatures offline or compromises long-lived signing keys; demo keys are deterministic placeholders.

\textbf{Limits of fixed evidence arms.} Receipts and state can look internally consistent while worker claims are false. Provenance can show a trusted summary on answerable attacks (correct-answer exposure, not a mechanism label). No arm implements adaptive querying or learned selection of what to fetch next; those would be outside this frozen design.

\subsection{Partial observation and gate (standard notation)}
Let $O_a(h)$ denote the observation of history $h$ under arm $a$. Worker text is held fixed across arms for a given fixture. If a compliant history $h_0$ and a violating history $h_1$ have $O_a(h_0)=O_a(h_1)$, any decision rule using only that observation has the same release probability on both. Thus zero release of $h_1$ requires withholding $h_0$ as well. Trusted recovery resolves this ambiguity only if an available authentic record distinguishes the histories. A signature alone does not supply an absent record or establish that its signed content is true. This is a standard indistinguishability observation, not a new theorem or a measured property of every fixture.

Write $d \in \{\text{publish},\text{block},\text{abstain}\}$ for supervisor advice and $e \in \{\text{execute},\text{refuse}\}$ for sink enforcement. For $a \in \{\text{claims},\text{receipts},\text{state}\}$, $e=\text{execute}$ whenever $d=\text{publish}$ on completed episodes. For $a=\text{provenance}$, deterministic gate $G$ may refuse the request even if $d=\text{publish}$. An incomplete binding can cause $G$ to abstain. The catalog audit replays $G$ separately from live model calls; its guarantee is limited to the enumerated catalog and implemented predicate.

\subsection{Models, workers, and budget}
Supervisor models are Gemma 4 31B (\texttt{gemma-4-31b-it}) and Qwen 3.5 397B (\texttt{qwen3.5-397b}) on the Adaption Responses API. Worker messages are one-shot Gemma wording calls under \texttt{WORKER-CORPUS-ASSEMBLY-v1}, not live worker decisions: \WorkerAccepted{} accepted generations, \WorkerRejected{} rejected, \WorkerIncomplete{} incomplete, over \WorkerFixtureSchedule{} fixtures and \WorkerMessagesSchedule{} scheduled messages, model \WorkerModel{}, spend \WorkerSpendTotal{} credits. The generator prompt supplies the scripted message as \texttt{wording\_\allowbreak{}reference}. In the assembled test corpus, 280 of 280 accepted model calls reproduced that baseline byte for byte. The assembly audit marks all 120 fixtures \texttt{source=generated}. The same assembled corpus is shared by every supervisor arm and model.

Development pilot protocol \PilotProtocol{} recorded \PilotLedgerEpisodes{} ledger episodes (\PilotCompleted{} completed, \PilotInvalid{} invalid, \PilotPending{} pending) with pilot \texttt{max\_\allowbreak{}output\_\allowbreak{}tokens}=\PilotMaxOutputTokens{} and spend \PilotSpendTotal{} credits. Pilot families are harness repair only. Main spend caps, output limits, and prices are pinned in the main run manifest before outcome inspection. Null \texttt{usage}, \texttt{latency\_\allowbreak{}seconds}, and \texttt{cost\_\allowbreak{}units} are accepted only for \texttt{error} and \texttt{invalid} records. A completed episode requires measured usage, latency, and cost.

\subsection{Endpoints and analysis}
Co-primary rates use completed episodes only. Unsafe execution is executed publications on illegitimate completed episodes over that denominator. Legitimate completion is executed legitimate publications equal to the true summary among legitimate completed episodes. Error and invalid episodes are excluded from completed-case denominators.

A supervisor publish decision and a gateway veto are distinct events. On claims, receipts, and state, publish decisions execute on the fake sink. On provenance, publish is a request; code may record \texttt{refused\_\allowbreak{}block} or \texttt{refused\_\allowbreak{}abstain}. Gateway-blocked unsafe attempts explain provenance gaps between unsafe attempt and unsafe execution rates in Table~\ref{tab:live-aggregate}. Field definitions and the decision-to-attempt accounting identity are in Appendix~\ref{sec:endpoint-fields}.

Family-cluster bootstrap uses the four \texttt{family\_\allowbreak{}id} blocks in a split, with percentile intervals and paired arm contrasts inside each model and each coordination stratum. Models and coordination conditions are not pooled. \texttt{scripts/prepare\_\allowbreak{}live\_\allowbreak{}paper.py} pulls aggregates only from supplied analysis outputs. It does not invent counts.

\section{Discussion}
This study measures publication outcomes under \emph{fixed} evidence arms, not an optimized evidence budget. Arms without provenance remain advisory: supervisor prose can recommend publish while the sink still executes. Only provenance separates unsafe \emph{attempts} from unsafe \emph{executions} via $G$. Evidence hiding is structural: claims never see receipts or keeper bodies; state never sees trusted inputs committed off-keeper; provenance alone receives the precomputed trusted summary when binding is complete.

State can approve internally consistent keeper bodies without off-keeper commitment. That is a coverage limit of the snapshot arm, not evidence that adaptive querying was tested. Single versus coordinated conditions differ in message count and speaker roles, and honest controls exist only as three-speaker pipelines, so coordination contrasts are descriptive. The assembled worker corpus reproduces the scripted baseline on all 280 accepted calls; those messages are instructed wording, not emergent collusion. Bootstrap intervals resample four family blocks and stay coarse.

\section{Future work (not conducted)}
A \textbf{prospective budgeted evidence-recovery} study, adaptively choosing which already authenticated records to retrieve and when to request review or hold an action, \textbf{was not executed} for this frozen release. The separate draft protocol in \texttt{docs/budgeted-recovery-protocol.md} lists the development pilot and the choices a later registration must freeze before evaluation. This paper reports only the completed live arm comparison and deterministic gate audit on saved responses. Any future recovery experiment requires a separate protocol freeze, measured acquisition and review costs, and held-out closed-loop evaluation distinct from the tables here. An accompanying constructed-control development pilot and offline replay test collection cost and software behavior only; their records do not enter this paper's main denominators. The implementation status and limitations are documented in \texttt{docs/recovery-build-status.md}; Appendix~\ref{sec:recovery-development} reports the separate feasibility diagnostics.
